# Flujo de Trabajo con Git y GitHub

1. **Trabajar siempre en local**: Nunca realizar `git commit` ni `git push` a GitHub automáticamente tras realizar un cambio.
2. **Subida manual solicitada por el usuario**: Solo realizar `commit` y `push` cuando el usuario lo solicite expresamente indicando el título/mensaje del commit.
3. **Confirmación cuando no se indique nada**: Si el usuario no menciona la subida a GitHub, trabajar en local y al finalizar la tarea preguntar si desea subir los cambios a GitHub, sugiriendo un título breve y descriptivo a modo de resumen.
